# Demo Runbook

1. Start backend and frontend.
2. Open the dashboard and point out receive-only, no return path, and payload decryption off.
3. Select an actual JSONL/PCAP source in Replay Lab.
4. Start replay and show ingest, feature, detector, and alert metrics.
5. Open `/alerts` to inspect evidence and acknowledge/resolve an alert.
6. Open `/performance` for measured runtime counters and `/architecture` for the passive flow.

No attack, model, throughput, confidence, or alert values are fabricated. Parts 9 scenarios remain empty until actual controlled files and ground truth are supplied.
