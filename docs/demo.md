# Part 1 Demo

Start backend and frontend locally or with Docker Compose. Open the dashboard and verify the visible posture indicators: `RECEIVE ONLY: ACTIVE`, `RETURN PATH: NONE`, and `PAYLOAD DECRYPTION: OFF`.

The alert list and traffic panels remain empty/zero by design. Part 1 does not fabricate attack alerts, throughput, latency, or model output. Use `/api/docs` to inspect the contracts and `/ws/events` to receive the initial heartbeat.
